Why Huajiao

不是又一个对话框，是长篇的结构引擎

聊天窗口擅长写一段；长篇需要「记得住、对得上、收得回」。花椒写作为这三件事而生。

结

结构化创作资产

人物、地点、设定、伏笔、时间线、关系网全部落成表格化资产。改一处，全局口径同步，不用再复制粘贴设定文档。

络

智能上下文组装

写第 20 章时，系统知道该带上谁的近况、哪条伏笔还没收、上一章停在哪。生成前可预览「带了哪些来源」。

忆

语义回忆

向量检索 + 关键词兜底，从百万字稿里找回「那把伞」在哪一章出现过。回忆命中率可测、可回归。

校

一致性巡检

时间线冲突、人物性格漂移、设定打架——巡检结果带章节定位，点开就能改。伏笔漏收一眼可见。

模

多模型路由

大纲用强模型，润色用快模型，本地模型可离线。支持 DeepSeek / OpenAI / Kimi / 智谱 / 通义 / Ollama 等。

书

一键成书

导出规范级 EPUB 3（可直接自出版）、投稿用 DOCX（A4 中文排版）、Markdown / HTML / JSON 全量备份。

Workflow

从一句灵感到可出版的书

立项

题材、基调、篇幅。AI 可推荐选题方向，你拍板。

建档

巡检

成书

Models & Privacy

模型是工具，稿子是你的

云端可一键关闭；也可以全程只用本机模型。AI 用量页显示每次带了哪些来源、各花多少 token。

接得上的模型

云端 DeepSeek OpenAI Kimi 智谱 通义 硅基流动 OpenRouter
  • 本地：Ollama / LM Studio / 任意 OpenAI 兼容端点
  • 任务路由：大纲、正文、对白、抽取可各用各的模型
  • 没有 Key 也能验证整条链路（自带 mock 模型脚本）

数据与隐私

  • 作品存在浏览器 IndexedDB，默认不出本机
  • 「隐私」页关闭云端后，只允许本机模型参与生成
  • AI 调用只发送必要上下文，来源与 token 可审计
  • 支持 gzip 全量备份 / 一键从 JSON 恢复
  • 设备授权：授权码激活，断网宽限期不锁作者
Ship the book

写完，就能交出去

导出不是「贴进 Word」，而是按阅读器与编辑部的标准生成。

E

EPUB 3

mimetype 首位不压缩、nav + NCX、OPF 元数据规范级，可直接上传自出版平台。

D

DOCX 投稿

真 OOXML，A4、中文首行缩进、章节分页，打开就是编辑熟悉的稿面。

J

JSON / MD / TXT

结构化全量备份可原样恢复；Markdown 丢进 Obsidian 也顺手。
