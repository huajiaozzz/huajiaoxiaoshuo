把长篇小说
写成 AI 也读得懂 的结构

人物、世界观、伏笔、时间线——都是可被 AI 读取的创作资产。每次生成，自动组装正确的上下文。

Library

所有作品，在一张安静的桌面上

本地优先：稿件存在你的浏览器里，随时全量备份。

Start

从一句灵感到完整立项

题材、基调、篇幅一次定清；AI 可推荐选题方向。

Overview

进度、字数、下一章，一目了然

创作驾驶舱让你知道现在写到哪、还差多少。

Cast

人物是结构，不是聊天记录

小传、目标、性格弧光落成卡片——AI 写对白时真正「认识」他们。

World

设定库：改一处，全文口径同步

地理、规则、时代、组织——长篇不再写崩设定。

Outline

卷、章、幕，像搭脚手架一样搭故事

大纲可拖拽调整；每一章都挂得上上下文与目标。

Write

写作台：生成之前，先看见带了什么

本次上下文来源可追溯——人物近况、未收伏笔、上一章结尾、文风样本。

Threads

伏笔有状态：埋下、待收、已回收

再长的故事，也不会把那把伞忘在第 3 章。

Timeline

时间线对齐，冲突自己跳出来

事件排序、因果、跨度——巡检帮你抓「穿帮」。

Graph

关系网一展开，人物不再「工具人」

势力、亲疏、隐秘关联，一眼看清。

AI Studio

多模型路由：大纲用强模型，润色用快的

DeepSeek / Kimi / 本地 Ollama……任务各走各的路。

Insights

文风指纹与写作趋势

知道自己写成什么样，才能稳定地写下去。

QA

一致性巡检：问题清单直达章节

性格漂移、设定打架、漏收伏笔——点开就能改。

Usage

每一次生成，token 花在哪都看得见

来源可审计，成本不神秘。

Export

写完，就能交出去

规范级 EPUB 3 · 投稿 DOCX · JSON 全量备份。

Models

模型是工具，稿子是你的

云端可关闭，本地可离线。数据默认不出本机。
